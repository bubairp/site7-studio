# Form Implementation Guide (`_forms` folder)

This guide explains how to use the unified form system in the `_forms` folder. The system is designed for **maximum flexibility** with **minimal JavaScript effort**.

## 🚀 Quick Setup (New Forms)
To create a new form that uses professional validation and AJAX, follow these steps:

1.  **Template Location**: Create your form in `templates/_forms/your-form.twig`.
2.  **Form Tag**: Use the `.needs-validation` class and data attributes for behavior:
    ```twig
    {{ form.open("", {
        'class': 'needs-validation',
        'data-ajax': 'true',                 {# Set to 'false' for page reload #}
        'data-loading-text': 'Sending...',    {# Custom loading text #}
        'data-recaptcha-key': getenv('...'), {# Optional reCAPTCHA #}
        'data-success-wrapper': 'form-success-id' {# DIV to show on success #}
    }) }}
    ```
3.  **Submit Button**: Give your button the `.wf-submit-btn` class and include a `.button-text` span and a spinner:
    ```html
    <button class="wf-submit-btn">
        <span class="button-text">Submit</span>
        <span class="spinner-border spinner-border-sm d-none"></span>
    </button>
    ```

## 🛠️ Key Components

### 1. The Global Handler (`form-validation.js`)
Located in `frontend/src/js/components/form-validation.js`. It handles:
- **Standard Validation**: Bootstrap 5 front-end validation.
- **reCAPTCHA v3**: Automatic token generation and injection.
- **Hybrid Submission**: Supports both AJAX (Fetch) and standard page-reload.
- **Loading State**: Automatically disables the button and shows the spinner.

### 2. The Twig Template (`contact.twig`)
Features a dynamic management system at the top of the file:
- **`columnMapping`**: Controls Bootstrap column widths (e.g., `col-md-6`) per field.
- **`submitButtonLabel`**: Controls the default button text.
- **`submitButtonLoadingLabel`**: Controls the text shown during submission.

## ⚠️ Troubleshooting (403 Errors)
- **DOM Clobbering**: Ensure no form field is named `action` (e.g., `<input name="action">`). This will break the form's ability to find its URL.
- **CSRF**: The handler automatically uses the standard CSRF hidden input generated by Craft. Do **not** manually add `data-csrf` attributes unless needed for a standalone form.

## 🧹 Maintenance
Whenever you change the JavaScript logic, remember to run your build process:
```bash
npm run dev
```
